# 专注辅助阅读：蓝图与基础实现

## 目标与交互

提供两个独立、默认关闭的阅读辅助功能。定位为个人阅读偏好，不作医疗效果承诺。

1. **渐变字色**：正文在「强调色 1 → 正文字色 → 强调色 2 → 正文字色」之间连续循环。渐变沿斜向分布，各段使用不同的相位，翻页后根据阅读位置改变相位，避免相邻行纵向堆成大片同色，也避免每一页呈现相同的配色分布。支持预设与自定义两种强调色。
2. **闪读**：当前可见页被拆为短语，以固定注视点展示；上下短竖线对准同一个强调字。中文优先按标点与短句切分，英文按词切分，保留标点，不拆坏 Unicode 字符。默认强调字为红色。
3. **节奏**：每个片段停留 0–2 秒，步进 0.1 秒；0 秒表示手动。开启后先暂停，用户主动播放。左滑／右箭头前进，右滑／左箭头回看，空格播放或暂停；手动操作暂停自动播放，给用户重新掌握节奏的机会。
4. **阅读连续性**：从当前可见页开始，读完后推进到下一页／下一屏，遇到末尾停止。保留原阅读器的定位与进度机制。退出闪读回到当前页，后台、切换书籍或关闭视图时停止计时。

## 设置与视觉

- 全局设置与阅读器内提供相同的「专注辅助」配置：两个独立开关、渐变配色、自定义强调色、闪读停留时间、闪读正文／强调字色。
- 设置即时写入现有持久化阅读设置；旧设置缺少字段时使用默认值。
- 阅读器直接更新真实正文／闪读窗口；设置区同时提供小型实时示例，方便在尚未打开书时调整。闪读设置预览需主动播放，避免不必要的自动闪动。
- 沿用 ReadAny 的排版、主题与控件，采用克制的阅读纸面效果；固定注视点、上下细线与强调字为主要视觉锚点。弹层应可滚动，手机宽度下控件不溢出。

## 技术路径

- `core/reader` 保存共享配置、归一化、分词、渐变和闪读 DOM 控制器；桌面直接导入，移动 WebView 构建时打包同一份实现。
- 渐变只添加可撤销的样式和标记，不拆分或替换书籍文本节点，保护 EPUB CFI、选区、笔记与搜索。通过重复斜向渐变、段落偏移及页位置偏移产生字色变化；基础版不做逐行 Range 测量。
- 闪读窗口位于书籍 iframe 外层，读取已有可见文本接口，通过原有翻页接口跨页，不改写书籍正文。异步翻页期间锁住推进，防止计时和滑动重复消费文本。
- 固定版式、扫描图片与无文本书籍不强制染色；有可提取文本时可闪读，无文本时明确显示空态。
- 所有书籍文本通过 `textContent` 呈现；颜色限制为合法十六进制颜色，设置导入后也重新归一化。

## 基础验收

- 开关与颜色可持久化，两端重开设置后值一致；关闭渐变后恢复书籍原样式。
- 单段跨行、长段跨页、跨章节及深浅主题下，字色持续循环，行间与页间相位变化。
- 中文、英文、混合标点、emoji 与组合字符切分不丢字；强调位置只选择文字／数字。
- 0 秒不创建播放计时器；0.1 秒与 2 秒边界正确，暂停／左滑／关闭／后台均取消旧计时。
- 跨页推进不重复读同一页；空页或书尾停止；左右滑与空格不会穿透为正文翻页。
- 核心单元测试、两端类型检查、移动 reader 打包及浏览器交互检查。

## 后续增强

精确逐行颜色连续衔接、按语言的智能短语分组、按片段保存恢复位置、固定版式 OCR，以及与听书的统一播放互斥，作为后续增强；基础版的闪读位置随当前页保存。
