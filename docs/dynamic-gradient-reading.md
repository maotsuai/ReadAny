# 动态渐变阅读：设计与基础实现

## 交互

在现有专注辅助设置里增加独立的「动态变色」开关，默认关闭；开启会同时启用渐变字色。桌面、移动端的全局设置和阅读器内设置使用同一组持久化参数，实时预览使用同一动画引擎。关闭后恢复静态渐变，不改变原文、字号、选区和 EPUB CFI。

## 五种变色方式

| 模式 | 视觉 | 参考思路 |
| --- | --- | --- |
| 流光漫游 | 连续移动重复渐变的相位 | 屏保的色带流动、调色板循环 |
| 潮汐往返 | 色带缓慢往返，平滑转向 | 漂浮波纹、往复轨迹 |
| 极光舒展 | 小幅色相游走，色带宽度和方向轻微变化 | 极光、Flurry 的流动色彩 |
| 棱镜游色 | 两个低饱和强调色沿色环反向游走 | Drift 的 hue cycling、Flurry 的 Slow Cyclic |
| 水墨融色 | 两种墨色交融后回归，亮度保持稳定 | 屏保中的缓慢调色与渐融 |

这些是针对阅读重新设计的效果，不直接复制屏保的粒子、高亮光带、频闪或全屏动态背景。屏保参考包括作者提供的 [Flurry 配色说明](https://apps.apple.com/jm/app/flurry-screensaver/id991374400)（Slow Cyclic、Cyclic、Tiedye 等）和 [Drift 原版手册](https://man.archlinux.org/man/extra/xscreensaver/drift.6.en)中的色相循环。

## 必须持续随机的速度

- 范围用「每轮约需多少秒」表达：秒数越小越快，默认 **20–45 秒**。
- 允许范围 **8–120 秒**，上下限至少相差 **4 秒**；UI 无法设成固定值，导入、同步或旧设置中的相同上下限也会重新归一化。
- 实际控制的是连续相位速度：始终位于 `1 / 最慢秒数` 与 `1 / 最快秒数` 之间。
- 每 **3–7 秒**重新随机目标速度，并用三次平滑插值过渡。不是只在启动时抽一次固定速度，也不是不断重启 CSS animation。
- 不自动随机切换模式，避免不必要的视觉突变。改变模式或配色由用户明确操作。
- 暂停、后台、丢帧后不快进补播；回到前台从原相位继续。较长掉帧会放慢实际效果，不追赶时间。

## 光敏与可访问性边界

**8 秒不是医学安全阈值，也不宣称任何效果能保证不引发癫痫。** 除变化速度外，亮度、饱和红、画面面积、观看距离和个人情况也有关。[W3C 对闪烁阈值的说明](https://www.w3.org/WAI/WCAG22/Understanding/three-flashes-or-below-threshold.html)明确区分一般闪烁和饱和红闪烁，并说明观看条件的局限。

本实现采取保守约束：

- 只改变字色和颜色分布，不改变文字的位置、尺寸、透明度及纸张背景。
- 不做明暗呼吸、开关闪烁、频闪、色彩瞬切、随机跳帧或全屏亮暗交替。
- 动态色使用 OKLab 色相变换，限制色度，并将各强调色调整回接近原来的相对亮度；低饱和度限制同样用于自定义高饱和红色。
- 保持文字对比度；静态字体与标注的布局不受影响。
- 遵循浏览器 `prefers-reduced-motion`，移动端额外读取并监听原生 `AccessibilityInfo`。查询完成前先保持静态。
- 阅读器不活跃、进入后台或打开闪读时冻结渐变；关闭动态开关即可停止。预览也服从后台和减少动态效果设置。
- 一个文档共享一个时间轴，20 fps 更新绘制变量；离开页面、卸载 iframe 或退出阅读器时取消动画并移除监听。

对应参考：[暂停、停止、隐藏](https://www.w3.org/WAI/WCAG22/Understanding/pause-stop-hide.html)、[遵循减少动态效果](https://www.w3.org/WAI/WCAG22/Techniques/css/C39)。这些工程约束和单元测试不等于医学安全验证，也不等于经过专业闪烁分析工具认证。

## 验证

- 设置归一化：越界、反向、相同上下限和旧设置。
- 随机时间轴：持续变化、速度边界、加减速连续、暂停／掉帧不追赶。
- 五种模式：周期接缝连续，只有颜色绘制变化，没有 opacity 或背景亮暗动画。
- 色彩：色相变化时相对亮度稳定，高饱和红被降色度，深浅及纸张主题保持对比度。
- 生命周期：系统减少动态效果、原生偏好覆盖、后台冻结、iframe 卸载清理。
- 两端类型检查、移动阅读器与预览构建、浏览器效果与设置交互验证。真机验证与专业闪烁分析仍需后续完成。
